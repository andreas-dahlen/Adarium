Command	                    Purpose

cargo new name	            Create a project
cargo init	                Initialize project in current directory
cargo build	                Compile project
cargo build --release	      Optimized compilation
cargo check	                Check code without producing executable
cargo run	                  Compile and execute binary
cargo test	                Run tests
cargo add package	          Add dependency
cargo remove package	      Remove dependency
cargo update	              Update dependencies within version constraints
cargo clean	                Remove build artifacts
cargo doc --open	          Generate and open documentation
